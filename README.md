# Shiori

**日本語** ・ [English](README.en.md)

配信で見ているアニメの場面を、キー 1 つで画像や動画クリップとして残し、
あとから元の動画のコマ単位で見返せる Windows 用のデスクトップアプリです。

**コアコンセプト：「狙ったコマを撮った瞬間、整理まで終わっている」**

撮った瞬間に作品名・再生位置・視聴 URL が記録されるので、撮ったあとに整理する手間がかかりません。

## はじめる

Shiori は、デスクトップアプリとブラウザ拡張の 2 つで動きます。

1. [GitHub Releases](https://github.com/salty032/shiori/releases) から最新のインストーラー（`Shiori-Setup-x.x.x.exe`）をダウンロードして実行します。
2. アプリに付いてくるブラウザ拡張を、ブラウザに読み込みます（Chromium 系ブラウザと Firefox 142 以降）。
3. ブラウザのハードウェアアクセラレーションをオフにします。オンのままだと、撮った映像が真っ黒になります。

2 と 3 は、アプリを開くと「Shiori のセットアップ」が順に案内します。
くわしい手順は [インストール](manual/getting-started/installation.ja.md) にあります。

## できること

- **キー 1 つで撮る・録る**：`Alt+S` で画像を、`Alt+D` で最長 30 秒の動画クリップを残せます。撮る瞬間はプレーヤーの表示が消え、映像だけが写ります。
- **元の動画の 1 コマずつ送れる**：録ったクリップは `,` / `.` で元の動画のコマ単位で送れます。24fps / 30fps の動画はコマ精度を保証し、撮り逃したコマは画面に出します。
- **タイムシート**：コマ送りしながら動画番号を打ち、東映デジタルタイムシートに貼り付けられる形でコピーできます。
- **探す・整理する**：作品名・メモ・タグ・日付・サイトで絞り込み、条件をスマートフォルダとして残せます。AI による自動タグ付け（WD Tagger）も使えます。
- **すべて PC の中**：撮ったものも記録も PC の中だけに保存し、外へ送りません。
