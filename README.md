# Shiori

アニメ視聴中にキャプチャした画像を管理するデスクトップアプリ（Windows）。

**コアコンセプト：「狙ったコマを撮った瞬間、整理まで終わっている」**

グローバルホットキーで配信プレーヤーの画面を撮影すると、タイトル・再生時刻・URL を
自動で記録。WD Tagger による自動タグ付け・タグ/日付フィルターに対応します。

---

## 主な機能

- **ワンキー・キャプチャ**：`Alt+S` で再生中プレーヤーをキャプチャ（プレーヤーUIは自動で非表示）
- **動画クリップ録画**：`Alt+R` で再生中プレーヤーの短いクリップを録画（著作権対策として最長 **60秒** 固定）。録画後はアプリ内でトリミング・再生が可能
- **自動メタデータ**：作品タイトル・再生タイムコード・視聴URLを自動記録
- **自動タグ付け**：WD Tagger（ローカルAI）でキャプチャ内容を自動タグ化
- **検索・フィルター**：タイトル/メモ検索、タグ（AND/OR）、日付、サービスで絞り込み
- **グリッド/タイムライン表示**：ドラッグ矩形選択、Shift/Ctrlクリック、矢印キー移動でまとめて整理
- **コマ送り**：プレーヤー上で `Shift+←/→`
- **ローカル取り込み**：`Ctrl+V` でクリップボードの画像を貼り付け、または画像・動画（`.webm` / `.mp4`、60秒以内）フォルダをドロップして一括取り込み
- **エクスポート**：選択画像をそのままファイルコピー
- **データ書き出し/読み込み**：ライブラリ全体（キャプチャ分）を metadata 付きで書き出し／読み込み

## インストール

> ⚠️ Shiori は **デスクトップアプリ** と **ブラウザ拡張** の 2 つで動作します。両方のセットアップが必要です。
> 拡張は Chrome / Edge / Vivaldi / Brave / Opera などの Chromium 系ブラウザと Firefox 142 以降に対応します。

### 1. アプリ本体

[GitHub Releases](https://github.com/salty032/shiori/releases) から最新のインストーラー（`Shiori-Setup-x.x.x.exe`）を
ダウンロードして実行します。

> 未署名ビルドのため、初回起動時に Windows SmartScreen の警告が出る場合があります。
> 「詳細情報」→「実行」で進めてください。

### 2. ブラウザ拡張のサイドロード（Chromium 系）

1. Shiori を起動し、初回起動画面（ライブラリが空のとき）、または 設定 → 基本 → 拡張機能 にある
   「拡張機能フォルダを開く」ボタンをクリック
   （このフォルダはアプリの更新時に自動で同期されます。手動で探す場合は `%APPDATA%\Shiori\extension` ）
2. 使っているブラウザの拡張機能ページを開く（Chrome: `chrome://extensions`、Edge: `edge://extensions`、
   Vivaldi: `vivaldi://extensions`、Brave: `brave://extensions` など、いずれも Chromium 系は同様の操作）
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」→ 手順1のフォルダを選択

拡張がアプリに接続すると、キャプチャ時にプレーヤー情報が自動で送られるようになります。

### 3. ブラウザ拡張のサイドロード（Firefox）

1. Shiori の設定 → 基本 → 拡張機能にある「拡張機能フォルダを開く」をクリック
2. Firefox で `about:debugging#/runtime/this-firefox` を開く
3. 「一時的なアドオンを読み込む」から、手順1のフォルダ内の `manifest.json` を選択

> 一時的に読み込んだ拡張機能は Firefox の終了時に解除されます。継続利用する場合は、
> 署名済みの Firefox 用拡張パッケージを使用してください。

### 4. アップデートについて

初回インストール後は、新しいバージョンをバックグラウンドで自動ダウンロードします。
ダウンロードが終わるとアプリ内にバナーが表示されるので、「再起動して更新」を押すと
その場で適用されます（手動でのダウンロード・実行は不要）。

### 5. ブラウザのハードウェアアクセラレーションをオフにする

> ⚠️ **重要**：ブラウザのハードウェアアクセラレーションが有効なままだと、
> キャプチャした画像や録画クリップが黒く（映像部分が真っ暗に）なってしまいます。必ずオフにしてください。

各ブラウザの設定から無効化します（設定変更後はブラウザの再起動が必要です）。

- Chrome: 設定 → システム →「ハードウェア アクセラレーションが使用可能な場合は使用する」を OFF
  （`chrome://settings/system`）
- Edge: 設定 → システムとパフォーマンス →「使用可能な場合はハードウェア アクセラレーションを使用する」を OFF
  （`edge://settings/system`）
- Vivaldi / Brave / Opera など他の Chromium 系ブラウザも、システム設定に同様の項目があります
- Firefox: 設定 → 一般 → パフォーマンス →「推奨のパフォーマンス設定を使用する」を OFF にし、
  「ハードウェアアクセラレーション機能を使用する」を OFF

## 使い方

### 静止画をキャプチャする

1. ブラウザ拡張が有効な動画ページでアニメを再生する
2. 撮りたいコマで `Alt+S`
3. Shiori のギャラリーに自動でサムネイル・タイトル・タグが並ぶ

### 動画クリップを録画する

1. 対応サイトの動画を再生する
2. 録りたい場面の頭で `Alt+R`（録画開始／もう一度押すと停止。最長 **60秒** で自動停止）
3. 録画したクリップはギャラリーに追加され、開くとアプリ内で再生・トリミングできる

> 録画中はトレイアイコンで状態を示します（録画領域に重なる画面内表示は録画自体に写り込むため出していません）。
> `Alt+R` が効かない場合、他のアプリ（NVIDIA App などのオーバーレイ／録画ソフト）が同じキーを使っていることがあります。設定画面で別のキーに変更してください。

### 手元の画像・動画を取り込む

- `Ctrl+V` でクリップボードの画像を貼り付け
- 画像・動画ファイル（`.webm` / `.mp4`、60秒以内）やそれらを含むフォルダをウィンドウにドロップして一括取り込み

各ホットキー（キャプチャ／録画）は設定画面から変更できます。アプリはトレイに常駐し、ウィンドウを閉じても終了しません。

## 動作対象

HTML5 video ベースの主要な動画サイトで、タイトル・タイムコードの自動取得、
キャプチャ、クリップ録画、`Shift+←/→` のコマ送りを補助します。

一部サイトではページ構造に合わせてタイトル取得やプレーヤーUIの一時非表示を調整しています。

> 各サイトのページ構成変更により、一時的に取得できなくなる場合があります。
> 利用は各サービスの利用規約の範囲で行ってください（「免責事項」参照）。

---

## 自動タグ付け（任意）

設定 →「自動タグ付け」から WD Tagger モデルをダウンロードすると、
キャプチャ内容のAI自動タグ付けが有効になります。

> モデルは [HuggingFace](https://huggingface.co/SmilingWolf/wd-vit-tagger-v3) から
> ダウンロードされ、ローカルに保存されます。推論はすべて端末内で完結し、画像が外部に送信されることはありません。

---

## プライバシー

- キャプチャ画像・録画クリップ・メタデータ・タグはすべて **ローカル** に保存されます
- キャプチャ画像・録画クリップやメタデータを外部サーバーへアップロードする機能はありません
- モデルのダウンロード時は HuggingFace、アプリの更新確認・ダウンロード時は GitHub Releases に接続します
- ブラウザ拡張は拡張が有効な動画ページで、タイトル・再生位置・ウィンドウ位置・URL を取得し、
  ローカルの Shiori アプリ（`ws://127.0.0.1:39821`）にのみ送信します
