# コマ精度について

**日本語** ・ [English](frame-accuracy.md)

録ったクリップは、ビューアで `,` / `.` を押すと、元の動画を **1 コマずつ** 送れます。
ここでの 1 コマは、配信元の動画の 1 コマです。録画したファイルの 1 フレームではありません。

## 保証するのは 24fps / 29.97fps / 30fps まで

**24fps / 29.97fps / 30fps の動画は、コマ精度を保証します。**
Shiori が画面を取り込む間隔は約 20ms です（60Hz の画面で実測、毎秒約 50 枚）。
これは元の動画のコマの間隔（24fps なら 41.7ms、30fps なら 33.3ms）より短いので、すべてのコマを撮り切れます。
実測でも撮り逃しは 0 でした。

配信アニメのほとんどは 24fps（正確には 23.976fps）です。

## 60fps の動画は保証しない

**59.94fps / 60fps の動画は、コマ精度を保証しません。**
元の動画のコマの間隔（16.7ms）の方が取り込みの間隔より短いので、どうしても取り込めないコマが出ます。
録画そのものはできますが、取り込めなかったコマには、直前のコマの絵が出ます。

画面のリフレッシュレートを上げても、取り込みは毎秒約 50 枚で頭打ちになります（200Hz の画面で実測）。
60fps の動画のコマ精度は、どの画面でも保証しません。

## fps はどうやって決まるか

元の動画の fps は、録るたびに動画から測ります（設定 → キャプチャ → コマ送り の「自動検出」）。
自動検出を切ると、決めた fps で固定します。アニメなら約 24、実写なら約 30 です。

## 保証できないときは画面に出る

撮れなかったコマや、元の動画のどのコマか確かめられない箇所は、黙って隠さずに画面に出します。
何が出るかと、それぞれの意味は [画面の「撮り逃し」「抜け」「要注意」が意味すること](frame-markers.ja.md) にあります。
