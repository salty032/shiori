# ブラウザのハードウェアアクセラレーションを切る

**日本語** ・ [English](hardware-acceleration.md)

> **ブラウザのハードウェアアクセラレーションがオンのままだと、撮った画像や録画の映像部分が真っ黒になります。**
> Shiori を使う前に、必ずオフにしてください。

## 切り方

設定を変えたら、ブラウザを再起動してください。再起動するまでは切り替わりません。

**Chrome**：設定 → システム →「ハードウェア アクセラレーションが使用可能な場合は使用する」をオフ（`chrome://settings/system`）

**Edge**：設定 → システムとパフォーマンス →「使用可能な場合はハードウェア アクセラレーションを使用する」をオフ（`edge://settings/system`）

**Vivaldi / Brave / Opera など**：どれもシステムの設定に同じ項目があります。

**Firefox**：設定 → 一般 → パフォーマンス →「推奨のパフォーマンス設定を使用する」をオフにし、出てきた「ハードウェアアクセラレーション機能を使用する」もオフ

切って再起動したら、「Shiori のセットアップ」の 1 番目にある「オフにしてブラウザを再起動しました」に印を付けます。
