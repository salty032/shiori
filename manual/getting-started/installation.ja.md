# インストール

**日本語** ・ [English](installation.md)

Shiori は、**デスクトップアプリ** と **ブラウザ拡張** の 2 つで動きます。
アプリが画面を撮って保存し、拡張が「いま何をどこまで見ているか」（作品名・再生位置・URL）をアプリに伝えます。
どちらか片方だけでは撮れないので、両方を入れてください。

拡張は、Chrome / Edge / Vivaldi / Brave / Opera などの Chromium 系ブラウザと、Firefox 142 以降で動きます。

## アプリ本体を入れる

[GitHub Releases](https://github.com/salty032/shiori/releases) から、最新のインストーラー（`Shiori-Setup-x.x.x.exe`）をダウンロードして実行します。

署名していないアプリなので、初回は Windows SmartScreen の警告が出ることがあります。
「詳細情報」→「実行」で進めてください。

インストールが終わって Shiori を開くと、ライブラリが空の画面に「セットアップを始める」が出ます。
押すと「Shiori のセットアップ」が開き、ブラウザの準備から最初のキャプチャまでを 3 つの手順で案内します。
このページと次のページは、その手順をくわしく書いたものです。
途中で閉じても、サイドバーの「セットアップ」から続きを開けます。

## 拡張を読み込む（Chromium 系）

拡張はストアには出していません。アプリに付いてくる拡張のフォルダを、ブラウザに読み込ませます。

1. Shiori の「Shiori のセットアップ」、または 設定 → 基本 → 拡張機能 にある「拡張機能フォルダを開く」を押します。
   拡張のフォルダが開きます（`%APPDATA%\Shiori\extension`）。
2. ブラウザの拡張機能のページを開きます。
   Chrome は `chrome://extensions`、Edge は `edge://extensions`、Vivaldi は `vivaldi://extensions`、Brave は `brave://extensions` です。
3. 「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、手順 1 で開いたフォルダを選びます。

読み込めたら、対応サービスの動画ページを開いてください。
拡張がアプリにつながると、「Shiori のセットアップ」の 2 番目の手順に「動画ページから受信中」と出ます。

拡張のフォルダは、アプリを更新すると中身も新しくなります。読み込み直す必要はありません。

## 拡張を読み込む（Firefox）

1. Shiori の 設定 → 基本 → 拡張機能 にある「拡張機能フォルダを開く」を押します。
2. Firefox で `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」を押し、手順 1 で開いたフォルダの中の `manifest.json` を選びます。

> **Firefox では、Firefox を終了すると拡張が外れます。**
> Firefox は署名していない拡張を常に入れておくことを許していないため、
> Firefox を起動するたびに手順 2〜3 をやり直す必要があります。
> 毎回の読み込み直しを避けたいときは、Chromium 系のブラウザを使ってください。

## アップデート

新しい版が出ると、Shiori が裏でダウンロードします。
終わるとアプリの中にバナーが出るので、「再起動して更新」を押すとその場で新しい版になります。
押さずにアプリを終了した場合も、終了するときに更新され、次に開いたときは新しい版です。
インストーラーを自分でダウンロードし直す必要はありません。

## 次に読む

[ブラウザのハードウェアアクセラレーションを切る](hardware-acceleration.ja.md) に進んでください。
これを切らないと、撮った画像や録画が黒くなります。
