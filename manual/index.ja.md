# Shiori マニュアル

**日本語** ・ [English](index.md)

Shiori は、配信で見ているアニメの場面を、キー 1 つで画像や短い動画クリップとして残し、
あとから元の動画のコマ単位で見返せる Windows 用のアプリです。
