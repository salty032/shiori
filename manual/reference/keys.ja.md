# キー操作一覧

**日本語** ・ [English](keys.md)

アプリの中では、サイドバーの「?」からも同じ一覧を開けます。

## どこでも

| キー | すること |
|---|---|
| `Alt+S` | 撮る（設定で変えられます） |
| `Alt+D` | 録る・止める（設定で変えられます） |

## ブラウザの動画ページ（対応サービス）

| キー | すること |
|---|---|
| `,` / `.` | 1 コマ戻る / 進む |
| `M` | 音を消す / 戻す |

## 一覧

| キー | すること |
|---|---|
| `/` | 検索欄に入る |
| `T` | 選んでいるものにタグを付ける |
| `Ctrl+C` | 選んでいる画像をコピー |
| `Ctrl+V` | クリップボードの画像を取り込む |
| 矢印キー | 選択を動かす |
| `Ctrl+A` | すべて選ぶ |
| `PageUp` / `PageDown` | ページ送り |
| `Enter` | ビューアで開く |
| `Delete` | 消す |
| `Escape` | 選択を外す |
| `Ctrl+Z` | 元に戻す（削除の取り消し・選択の取り消し） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直す |

## ビューア

| キー | すること |
|---|---|
| `←` / `→` | 前 / 次へ |
| `,` / `.` | 1 コマ戻る / 進む（動画） |
| `Space` | 再生 / 一時停止（動画） |
| `M` | 音を消す / 戻す（動画） |
| `↑` / `↓` | 音量を 5% 上げる / 下げる（動画。タイムシートを開いているときはコマ送り） |
| ダブルクリック | ズームのオン / オフ（画像） |
| `+` / `-` / `0` | 拡大 / 縮小 / 元に戻す |
| `Tab` | 詳細パネルを出す / しまう |
| `Delete` | 表示しているものを消す |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |
| `Enter` / `Escape` | 閉じる |

## トリミング

| キー | すること |
|---|---|
| `,` / `.` | 1 コマ戻る / 進む |
| `I` / `O` | 開始にする / 終了にする |
| `Space` | 再生 / 一時停止 |
| `M` | 音を消す / 戻す |

## タイムシート（開いているとき）

| キー | すること |
|---|---|
| `0`〜`9` / `Enter` | 動画番号を打つ / 確定して次のコマへ |
| `F1` / `F2` / `F3` | ○（中割り）/ ●（逆シート）/ ×（カラ）。テンキーの `/` `-` `*` でも |
