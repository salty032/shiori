# Keyboard shortcuts

[日本語](keys.ja.md) ・ **English**

In the app, you can open the same list from the "?" in the sidebar.

## Anywhere

| Key | Action |
|---|---|
| `Alt+S` | Capture (can be changed in Settings) |
| `Alt+D` | Start / stop recording (can be changed in Settings) |

## Video pages in the browser (supported sites)

| Key | Action |
|---|---|
| `,` / `.` | Back / forward one frame |
| `M` | Mute / unmute |

## List

| Key | Action |
|---|---|
| `/` | Jump to the search field |
| `T` | Add a tag to the selected items |
| `Ctrl+C` | Copy the selected image |
| `Ctrl+V` | Import an image from the clipboard |
| Arrow keys | Move the selection |
| `Ctrl+A` | Select all |
| `PageUp` / `PageDown` | Page through |
| `Enter` | Open in the viewer |
| `Delete` | Delete |
| `Escape` | Clear the selection |
| `Ctrl+Z` | Undo (a deletion or a selection) |
| `Ctrl+Shift+Z` / `Ctrl+Y` | Redo |

## Viewer

| Key | Action |
|---|---|
| `←` / `→` | Previous / next |
| `,` / `.` | Back / forward one frame (video) |
| `Space` | Play / pause (video) |
| `M` | Mute / unmute (video) |
| `↑` / `↓` | Volume up / down 5% (video; steps frames while the timesheet is open) |
| Double-click | Toggle zoom (images) |
| `+` / `-` / `0` | Zoom in / zoom out / reset |
| `Tab` | Show / hide the details panel |
| `Delete` | Delete the item being shown |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Enter` / `Escape` | Close |

## Trimming

| Key | Action |
|---|---|
| `,` / `.` | Back / forward one frame |
| `I` / `O` | Set start / set end |
| `Space` | Play / pause |
| `M` | Mute / unmute |

## Timesheet (while open)

| Key | Action |
|---|---|
| `0`–`9` / `Enter` | Enter a drawing number / confirm and move to the next frame |
| `F1` / `F2` / `F3` | ○ (in-between) / ● (reverse sheet) / × (empty). The numeric keypad `/` `-` `*` also work |
