# 手元の画像・動画を取り込む

**日本語** ・ [English](importing.md)

配信から撮ったもの以外も、ライブラリに入れられます。

## 貼り付ける

画像をクリップボードにコピーしてから、Shiori で `Ctrl+V` を押します。

## ドロップする

画像・動画のファイルか、それらが入ったフォルダを、Shiori のウィンドウにドロップします。
動画は `.webm` / `.mp4` の 30 秒以内のものだけ取り込めます。
一度に取り込めるのは 200 件までです。

ライブラリが空のときの画面にドロップしても取り込めます。

## 取り込んだものの違い

取り込んだものには、作品名・再生位置・視聴 URL は付きません。必要なら詳細パネルで作品名を打ち、メモに書いてください。
取り込んだ動画は、ファイルの 1 フレームずつコマ送りできますが、タイムシートは開けません。
