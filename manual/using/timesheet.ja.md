# タイムシート

**日本語** ・ [English](timesheet.md)

録ったクリップをコマ送りしながら動画番号を打って、タイムシートを作れます。
作った表は、東映デジタルタイムシートに貼り付けられる形でコピーできます。

## 開く

ビューアでクリップを開き、タイムシートのボタンを押します。
詳細パネルと入れ替わりに、同じ場所に表が出ます。表には「秒」「コマ」「セル」「メモ」の欄があります。

<!-- スクショ: ビューアでタイムシートを開いたところ -->

開けるのは、24fps（配信では 23.976fps）の動画から録ったもので、コマ番号が元の動画と一致している録画だけです。
タイムシートは 1 秒 24 コマの表なので、30fps や 60fps の動画では、元の動画のコマが作画のコマと対応しません。
「要注意」が出ている録画（[画面の「撮り逃し」「抜け」「要注意」が意味すること](../concepts/frame-markers.ja.md)）や、手元から取り込んだ動画でも開けません。

## 打つ

表を開いている間は、キー操作を東映デジタルタイムシートに合わせています。

| キー | すること |
|---|---|
| `0`〜`9` | 動画番号を打つ |
| `Enter` | 確定して次のコマへ |
| `Backspace` | 消す |
| `↑` / `↓` | コマを送る |
| `←` / `→` | セルの列を移る（A〜G のどの列にも打てます） |
| `F1` / `F2` / `F3` | ○（中割り）/ ●（逆シート）/ ×（カラ）。テンキーの `/` `-` `*` でも打てます |

表を開いている間は、`←` / `→` を押しても前後のクリップには移りません。

## 灰色の行

撮り逃しや抜けのコマは灰色になり、打てません。絵がないので、打つなら前後から推し量って書くことになるからです。
表の見出しの「撮り逃し 3 コマ」は、撮り逃しの数です。

抜けの行は、何コマ抜けたかを推し量って差し込んでいます。そこが 1 コマ違うと、そこから下に打ったものは全部 1 つ隣のコマを指すことになります。

## コピーする

「コピー」を押すと、東映デジタルタイムシートに貼り付けられる形でクリップボードに入ります。
ボタンにカーソルを合わせると、何秒何コマぶんかが出ます。貼り付け先の欄や列は、自分で選んでください。

`.xdts` ファイルへの書き出しはありません。
