# ライブラリ

**日本語** ・ [English](library.md)

撮った画像とクリップは、すべてライブラリに並びます。
左がサイドバー、真ん中が一覧、右が詳細パネルです。

## 並べ方

サイドバーの下で、**グリッド** と **タイムライン** を切り替えられます。
グリッドは撮った順にサムネイルを敷き詰めます。タイムラインは作品ごとにまとめて時系列に並べるので、1 本の流れを追うときに向いています。

並び順は「新しい順」「古い順」「ランダム」から選べます。サムネイルの大きさはサイドバーで小・中・大を選べます。

## 選ぶ

クリックで 1 枚選び、`Shift` / `Ctrl` を押しながらクリックすると複数選べます。
何もないところからドラッグすると、四角で囲んだものをまとめて選べます。
矢印キーで選択を動かし、`Ctrl+A` ですべて選びます。`Escape` で選択を外します。

1 枚選ぶと、詳細パネルに作品名・再生位置・動画時間・FPS・解像度・サイト・取得日時・タグ・メモが出ます。
複数選ぶと、詳細パネルはタグの一括編集になります。

作品名は詳細パネルでダブルクリックするか `F2` で直せます。メモは打てばそのまま保存されます。

## 開く

ダブルクリックか `Enter` でビューアが開きます（[ビューアとトリミング](viewer.ja.md)）。

## 探す・絞り込む

画面の上の検索欄（`/` で入れます）に打つと、作品名とメモから探します。
次の書き方で絞り込めます。

| 書き方 | 意味 |
|---|---|
| `tag:タグ名` | そのタグが付いているもの |
| `site:サイト名` | そのサイトで撮ったもの |
| `type:` | 画像か動画か |
| `from:` / `to:` | 撮った日の範囲（`2026-01-01` / `2026-01` / `2026` の形） |

サイドバーのタグを押しても絞り込めます。もう一度押すと外れます。
条件を全部外すときは、一覧の「フィルタを解除」を押します。

## スマートフォルダ

絞り込んだ条件は、サイドバーの「スマートフォルダを保存」で名前を付けて残せます。
次からはサイドバーで押すだけで同じ条件になります。
スマートフォルダを消しても、消えるのは条件だけで、画像は消えません。

## ほかのアプリへ渡す

`Ctrl+C` で選んだ画像をクリップボードにコピーできます（動画はコピーできません）。
一覧からエクスプローラーや他のアプリへドラッグして渡すこともできます。
詳細パネルの「エクスポート」で、選んだものをフォルダへファイルとしてコピーできます（[書き出しの形式](../reference/export.ja.md)）。
