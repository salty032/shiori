# 設定

**日本語** ・ [English](settings.md)

設定は、トレイのアイコンを右クリックして「設定」から開けます。
「基本」「キャプチャ」「タグ」「データ」「情報」のタブに分かれています。

## 基本

**外観**：テーマ（システム / ダーク / ライト）と言語を選びます。

**起動**：「ログイン時に自動で起動する」をオンにすると、Windows にログインしたときに Shiori が立ち上がります。

**メモリ**：「ウィンドウを閉じたらメモリを解放する」をオンにすると、ウィンドウを閉じている間のメモリを減らせます。
代わりに、ウィンドウを開くときや録画を始めるときに少し待つことがあります。

**拡張機能**：「拡張機能フォルダを開く」と、拡張がつながっているか（「受信中」「未受信」）が出ます。
アプリの更新で拡張も新しくなったときは「再読み込みが必要」と出るので、ブラウザの拡張機能のページで再読み込みしてください。

## キャプチャ

**ホットキー**：撮るキー（既定は `Alt+S`）と録るキー（既定は `Alt+D`）を変えられます。
押しても何も起きないときは、ほかのアプリが同じキーを使っているかもしれません。

**コマ送り (, / .)**：元の動画の fps を録るたびに測るか（「自動検出」）、決めた fps で固定するかを選びます（[コマ精度について](../concepts/frame-accuracy.ja.md)）。

**通知**：撮り終えたとき、録り終えたときに Windows の通知を出すかを選びます。

## タグ

**自動タグ付け (WD Tagger)** と **サイドバー表示** があります（[タグと自動タグ付け](tags.ja.md)）。

## データ

**保存場所**：撮った画像とクリップの保存先を変えられます。
変えると、これまでのぶんも一緒に移します。移す前に件数と容量が出て、途中で止められます。
止めても失敗しても何も変わりません。移している間は、移す先に一時的に 2 倍の空きが要ります。
ドライブの直下は選べません。

**使用量**：画像と動画の数、それぞれが使っている容量が出ます。

**保存する解像度**：撮る画像の大きさの上限です。録画には効きません。
「自動」（既定）は配信の解像度に合わせ、引き伸ばされたぶんは保存しません。
「1080p」「720p」は、配信がそれより高いと画質が下がります。「上限なし」は画面に映っている大きさのまま保存します。

**動画の書き出し**：エクスポートするときのクリップの形式です（[書き出しの形式](../reference/export.ja.md)）。

**エクスポート / インポート**：ライブラリをまるごとフォルダへ書き出したり、書き出したものを読み込んだりします（[書き出しの形式](../reference/export.ja.md)）。

**サムネイルの修復**：一覧にサムネイルが出ない画像があるときに使います。

## 情報

バージョンと、使っているライブラリのクレジットが出ます。
